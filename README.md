# LState 设计稿

这是一个核心功能为在状态栏展示设备信息的工具

## 功能点

核心点，在于状态栏的图标，通过自定义的绘制，以此在状态栏直接展示最直观的状态数据

### 状态栏

状态栏中，将会以折线图的形式，展示 CPU、GPU、内存的占用情况。

CPU、GPU、内存，将分别以 红、绿、黄三种颜色展示。

折线图的 X 轴坐标表示过去1分钟的变化。

折线图的 Y 轴坐标表示占用的百分比（0% ～ 100%）。

折线图的高度会和其他状态栏图标持平（22 pt），宽度占用为（44 pt）。

同时，在旁边，还会展示一个网速的显示。网速会显示为双层，整体高度仍然会保持为 22pt 的限制内。

双层的网速，上方的文字展示上行网速、下方的文字表示下行网速。

### 信息窗口

点击状态栏图标后，将会展示信息气泡。

信息气泡里，将会详细展示 CPU、GPU、内存、网络的参数信息，以及相关的性能的占比。
